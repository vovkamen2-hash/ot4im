# 🎨 OT4IM - Интерактивное веб-приложение

Крутое веб-приложение с минималистичным дизайном и элегантными анимациями на ванильном HTML/CSS/JavaScript.

## ✨ Возможности

### 🎯 Основное
- **Минималистичный дизайн** - чистый, современный интерфейс
- **Полностью отзывчивый** - идеально работает на всех устройствах
- **Без зависимостей** - чистый ванильный JavaScript, HTML и CSS

### 🎬 Анимации

#### 1. **Анимации при загрузке**
   - Fade-in эффекты при появлении элементов
   - Slide-up анимации для текста
   - Bounce анимации для иконок

#### 2. **Hover эффекты**
   - Плавное масштабирование карточек
   - Изменение цвета и тени
   - Анимация линий под ссылками
   - Ripple эффект на кнопках

#### 3. **Параллакс эффекты**
   - Плавающие фигуры движутся при скролле
   - Разная скорость для разных элементов

#### 4. **Скролл анимации**
   - Появление элементов при достижении viewport
   - Плавное выделение активной секции в меню

#### 5. **Интерактивные элементы**
   - Счётчик с анимированным прогресс-баром
   - Модальное окно с плавным появлением
   - Форма с валидацией и уведомлениями
   - Интерактивная галерея с эффектами

## 🚀 Быстрый старт

1. Клонируйте репозиторий:
```bash
git clone https://github.com/vovkamen2-hash/ot4im.git
cd ot4im
```

2. Откройте `index.html` в браузере или используйте Live Server:
```bash
# Если у вас установлен Python 3
python -m http.server 8000

# Или если Python 2
python -m SimpleHTTPServer 8000
```

3. Откройте http://localhost:8000 в браузере

## 🎨 Кастомизация

### Изменение цветов
В `styles.css` измените CSS переменные:
```css
:root {
    --primary: #000;
    --secondary: #fff;
    --accent: #667eea;        /* Измените этот цвет */
    --text: #333;
    --light-bg: #f8f9fa;
    --transition: all 0.3s cubic-bezier(0.25, 0.46, 0.45, 0.94);
}
```

### Изменение скорости анимаций
Измените значение `--transition` для глобального изменения всех переходов.

### Добавление новых анимаций
Добавьте новые `@keyframes` в `styles.css` и используйте их с `animation` свойством.
